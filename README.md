# CodeAlpha Stock Trading Platform

## About the Project
This project is developed as part of the CodeAlpha Java Programming Internship.

The Stock Trading Platform simulates a basic stock trading environment using Java.

## Features
- Display stock market information.
- Simulate buying and selling stocks.
- Track portfolio performance.
- Manage stock transactions.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## How to Run
1. Download the StockTradingPlatform.java file.
2. Open the file in any Java IDE.
3. Compile and run the program.
